# Protocol

Strength training, planned and logged with precision.

Local-first Progressive Web App. Install from Safari on iPhone via **Add to Home Screen**.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

Next.js (App Router) · TypeScript · Tailwind · IndexedDB (`idb`) · recharts · lucide-react

Built against docs in `/docs` per the Cursor build plan (Phase 0 scaffold).
